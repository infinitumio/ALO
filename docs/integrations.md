# Integrations

ALO reads signals from the tools you already use. Each integration contributes structure, never content.

| | Tool | What it can contribute |
| --- | --- | --- |
| <img src="../assets/apps/github.svg" width="20" height="20" alt="" /> | GitHub | Commits, pull requests, reviews and issues, by repository |
| <img src="../assets/apps/slack.svg" width="20" height="20" alt="" /> | Slack | Active conversations by channel, with topics summarised on your device |
| <img src="../assets/apps/vscode.svg" width="20" height="20" alt="" /> | VS Code | Workspace, files edited and time in the editor |
| <img src="../assets/apps/word.svg" width="20" height="20" alt="" /> | Microsoft Word | Which document you worked on and for how long |
| <img src="../assets/apps/notion.svg" width="20" height="20" alt="" /> | Notion | Pages edited, by workspace |
| <img src="../assets/apps/figma.svg" width="20" height="20" alt="" /> | Figma | Files and frames you designed in |
| <img src="../assets/apps/calendar.svg" width="20" height="20" alt="" /> | Calendar | Meetings, so ALO knows when you were away from the keyboard |
| <img src="../assets/apps/files.svg" width="20" height="20" alt="" /> | Files | Documents you open or share into ALO |
| <img src="../assets/apps/terminal.svg" width="20" height="20" alt="" /> | Terminal and Git | Builds, test runs and commits |

## What integrations never read

Message bodies, document text, code, file contents, passwords or full URLs.

## On iPhone

iOS does not let apps observe other apps. ALO for iPhone captures through the Share Sheet, Shortcuts, Live Activities and widgets, and continues work that started on your Mac.

## Request an integration

Open an [integration request](https://github.com/infinitumio/ALO/issues/new?template=integration_request.yml). A link to the tool's public API documentation helps a lot.
