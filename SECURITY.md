# Security

ALO handles a record of your working life. We take reports seriously and will work with you to fix problems quickly.

## Supported versions

Security fixes ship in the latest release. Please update before reporting.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not open a public issue for security problems.

1. Use GitHub's private reporting: [Report a vulnerability](https://github.com/infinitumio/ALO/security/advisories/new).
2. Or email **security@[domain]**.
   > Placeholder: replace this address before public launch.

Include:

- The ALO version and operating system
- What you found and the impact you expect
- Steps to reproduce, or a proof of concept

Do not include your own activity history, and do not access data that is not yours.

## What to expect

- Acknowledgement within 3 working days
- An initial assessment within 10 working days
- Credit in the release notes once a fix ships, if you would like it

## Scope

In scope: the ALO applications published in this repository's Releases, the local agent and its loopback API, sync between your devices, and the ALO website.

Out of scope: third-party applications that ALO reads signals from, and issues that require an already compromised device.
