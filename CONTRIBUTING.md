# Contributing

ALO is currently developed privately. This repository holds releases, documentation and integration information, not the application source, so pull requests against the product cannot be accepted here.

Bug reports and integration suggestions are welcome through [GitHub Issues](https://github.com/infinitumio/ALO/issues/new/choose).

## Good reports

- **Bugs:** include your ALO version, operating system and the steps that lead to the problem.
- **Integrations:** name the application and link its public API documentation if it has one.
- **Features:** describe the problem first, then how it would help you remember or resume work.

## Keep your history private

Never attach activity history, databases, exports or screenshots that show other people's information. If logs are needed, remove anything personal first. ALO will never ask you to share your memory.

## Documentation fixes

Small corrections to the docs in this repository are welcome as pull requests.

## Security

Please report vulnerabilities privately. See [SECURITY.md](./SECURITY.md).
